## Getting Started

```bash

cd REPO
```

The main HTML file can be opened directly for a basic local preview. When supporting assets are present or browser security rules make `file://` access unsuitable, use a local server:


Open the following address in your browser:

```text
http://localhost:8000/
```
